# Журнал изменений релизов NVM
в этом документе описываются изменения в поведении NVM в каждой релизной версии.

## `0.1.1-prealpha` — 07.08.2026
```diff
+ Новая команда `compile`.
+ Возможность запускать NVM Assembly файлы командой `run`.
```

### Добавлено
- Команда `compile`. Компилирование NVM Assembly (`.na`) кода в NVM Bytecode (`.nb`).
- Запуск `.na`-кода командой `run`.
