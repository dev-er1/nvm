# NVM Release Changelog
This document describes changes to NVM's behavior in each release version.

## `0.1.1-prealpha` — 07.08.2026
```diff
+ New `compile` command.
+ Ability to execute NVM Assembly files using the `run` command.
```

### Added
- `compile` command. Compiles NVM Assembly (`.na`) code into NVM Bytecode (`.nb`).
- Execution of `.na` code via the `run` command.
