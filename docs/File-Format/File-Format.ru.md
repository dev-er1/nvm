## Порядок байт
Все многобайтовые целочисленные значения в формате NVM Bytecode хранятся в порядке байт **Little-Endian**.

---

## Структура файла в формате NVM Bytecode
| Смещение   | Размер   | Секция     |
|:----------:|:--------:|------------|
| 0          | 5 байт   | Magic      |
| 5          | 6 байт   | Версия NVM |
| 11         | —        | Байткод    |

---

## Magic сигнатура
Первые 5 байт файла должны быть:
```text
4E 56 4D 42 43
```
(`NVMBC`)

Это позволяет определить, что файл содержит байткод NVM.

---

## Минимальная версия NVM
Сразу после magic-сигнатуры располагаются **6 байт**, определяющие минимальную требуемую версию NVM.

Версия хранится в виде трёх последовательных значений типа `u16`.
```text
<u16><u16><u16>
```

Виртуальная машина должна сравнить минимальную требуемую версию, указанную в файле, со своей собственной. Если версия виртуальной
машины меньше требуемой, загрузка файла должна быть прервана с ошибкой о несовместимости версий.

## Байткод
После заголовка файла идёт поток инструкций. Каждая инструкция кодируется следующим образом:

### Кодирование инструкции
```
[опкод: u8]                  — OperationCode (см. opcode.rs)
[количество_операндов: u8]   — число операндов, 0–3
[операнд₁]                   — если количество ≥ 1
[операнд₂]                   — если количество ≥ 2
[операнд₃]                   — если количество ≥ 3
```

### Кодирование операнда
Каждый операнд начинается с тега (1 байт), за которым следуют данные:

| Тег | Тип        | Данные                                   |
|:---:|------------|------------------------------------------|
| 0x00 | Register   | 1 байт — номер регистра (`u8`)          |
| 0x01 | Immediate  | 8 байт — значение (`u64` Little-Endian) |

### Примеры

`NOP` (0 операндов):
```
[0x00] [0x00]
```

`MOVE r0, 42` (2 операнда: Register, Immediate):
```
[0x05] [0x02]
[0x00] [0x00]       ; reg(0)
[0x01] [0x2A 0x00 ... 0x00]  ; imm(42) LE
```

`IADD r0, r1, r2` (3 операнда: Register, Register, Register):
```
[0x07] [0x03]
[0x00] [0x00]       ; reg(0)
[0x00] [0x01]       ; reg(1)
[0x00] [0x02]       ; reg(2)
```
